# Black House

Aplicação de gestão para coaches, com frontend React/Vite, backend Node.js/Express e PostgreSQL.

## Referências

- Arquitetura atual: [`docs/ARQUITETURA-ATUAL.md`](docs/ARQUITETURA-ATUAL.md)
- Regras para não confundir: [`docs/REGRAS-PARA-NAO-CONFUNDIR.md`](docs/REGRAS-PARA-NAO-CONFUNDIR.md)
- Inventário da documentação: [`docs/INVENTARIO-MD.md`](docs/INVENTARIO-MD.md)

## Desenvolvimento

```bash
npm install
npm run dev
```

API e banco usam `.env` em `server/`. O schema canónico é `schema_adaptado_postgres.sql`.

Documentos antigos da raiz foram arquivados em `docs/arquivo/legado-md-2026-05-19/`.
